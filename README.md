# PDEA College of Engineering — IT Department Website

A static, multi-page website concept for the Information Technology (IT) Department at PDEA's College of Engineering, Manjari. The project presents department information, academic topics, faculty information, student clubs, and contact details through a simple HTML, CSS, and JavaScript interface.

> **Project status:** Student project / website prototype. Some sections currently contain placeholder content or sample details and should be verified before being used as official college information.

## Live Demo

- **Website:** https://it-dept-one.vercel.app/
- **Source code:** https://github.com/vaishnavii-jathar/IT-dept

## Features

- Multi-page navigation: Home, About Us, Courses, Faculty, and Contact Us
- Homepage introduction and quick-link cards
- Department mission and vision sections
- Laboratory and student-club sections
- Course-topic cards
- Faculty profile-card layout
- Contact information, embedded map, and a contact-form interface
- Responsive layout and mobile navigation menu
- CSS transitions and entrance animations
- Font Awesome icons and Google Fonts

## Tech Stack

- **HTML5** — page structure and content
- **CSS3** — layout, responsive styling, and animations
- **JavaScript** — mobile navigation toggle
- **Font Awesome** — icons
- **Google Fonts (Poppins)** — typography
- **Vercel** — deployment

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Homepage, department introduction, and quick links |
| `about.html` | Mission, vision, laboratories, and student clubs |

## Run Locally

No build step or package installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/vaishnavii-jathar/IT-dept.git
   ```
2. Open the project folder:
   ```bash
   cd IT-dept
   ```
3. Open `index.html` in a browser, or use the **Live Server** extension in Visual Studio Code.
